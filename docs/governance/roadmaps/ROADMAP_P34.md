# P34 Roadmap — Training Completion

P34 is an owner-prioritized corrective phase ahead of P22. It closes the gap
between the existing cloud fine-tuning control plane and a visible, usable local
training experience. After its Gate passes, LAES returns to P22.

1. Make the Chat training entry permanently visible and responsive.
2. Register trainable local model directories without arbitrary filesystem access.
3. Run bounded, cancellable LoRA jobs and expose real trainer metrics.
4. Add optional dependency installation to the one-click launcher.
5. Validate security, UI, backend, desktop, and launcher behavior.
