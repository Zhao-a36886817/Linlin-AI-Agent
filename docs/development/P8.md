# P8 — Frontend and Tauri Desktop Architecture Convergence

**Status:** LOCKED  
**Type:** Client architecture stabilization  
**Purpose:** Converge the web frontend and Tauri desktop shell on one maintainable UI architecture without duplicating the application UI.

## 1. Objective

Establish the canonical client structure:

`Shared React/Vite UI → API Client → FastAPI Backend`

with Tauri acting as the desktop shell/integration layer rather than a second independent UI implementation.

- `AI_COLLABORATION_CHARTER.md`

## 3. Allowed Work

- frontend/desktop source layout convergence;
- shared React component reuse;
- API client/base-URL/config normalization;
- development CORS/origin fixes required for supported frontend/Tauri origins;
- Tauri shell integration;
- desktop/frontend build configuration;
- client architecture tests/build checks.

## 4. Forbidden Work

- visual redesign unrelated to architecture;
- duplicating the full React UI into a second desktop codebase;
- backend Provider/Tool/Memory/RAG redesign;
- installer/signing/release automation unless explicitly included in an approved follow-up phase;
- hard-coded localhost assumptions that break packaged operation.

## 5. Architecture Invariants

- one primary React UI source of truth;
- desktop-specific behavior remains in the Tauri shell/integration boundary;
- backend communication goes through the API client abstraction;
- secrets are not stored in browser/localStorage merely for desktop convenience.

## 6. Deliverables

- documented canonical frontend/desktop layout;
- shared UI source of truth;
- portable API endpoint configuration;
- Tauri shell capable of building/checking without maintaining a duplicate app UI.

## 7. Acceptance Criteria

- frontend production build passes;
- desktop/Tauri check passes when Rust/Tauri is configured in the repository;
- no duplicated independently maintained primary UI remains;
- supported dev origins are explicit and minimal;
- desktop integration does not bypass Credential/Workspace security boundaries;
- P0-P7 validation remains green.

## 8. Required Validation

Frontend:

```bash
npm run build
npm run lint
```

Backend regression:

```bash
python -m pytest tests -q
```

Desktop when Tauri is configured:

```bash
cargo check
```

Use the repository-correct working directories and commands.

## 9. Completion Report

Report old/new UI ownership, desktop shell responsibilities, API configuration changes, CORS/origin changes, modified files, build/test results, and remaining packaging work.
