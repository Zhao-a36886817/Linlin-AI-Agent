# P31 — Conversational Code Integration

**Status:** READY  
**Type:** product-integration  
**Authority:** Project Owner request, 2026-08-09

## Objective

Embed the existing workspace-safe Code proposal workflow directly in Chat so one
selected provider/model can discuss a change, generate a complete-file proposal,
show content and diff, and explicitly apply or discard it without leaving the
conversation.

## Allowed Work

- Chat UI composition around the existing Code Generation API.
- Conversation-local code proposal cards, preview, diff, apply, and discard UI.
- Documentation, tests, and completion evidence required for this integration.

## Forbidden Work

- Bypassing Provider Runtime or Workspace Runtime.
- Automatic code write or execution.
- Training runtime, theme implementation, provider redesign, or unrelated work.

## Acceptance Criteria

- Chat can switch between normal conversation and workspace-safe code requests.
- The selected dynamic provider/model is used for both flows.
- Code output appears in the same conversation with target, content, warnings,
  diff, and pending/applied/discarded state.
- Apply retains the exact `APPLY CODE` confirmation and consent gate.
- Existing standalone Code UI remains compatible.
- Full regression and LAES Gate pass.
