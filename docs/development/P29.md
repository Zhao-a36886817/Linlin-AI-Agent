# P29 — One-click Launcher Reliability Hotfix

**Status:** READY  
**Type:** product-hotfix  
**Authority:** Project Owner's explicit one-click `.bat` request and blocking launcher evidence, 2026-08-09

## Objective

Restore reliable one-click startup/shutdown after the browser profile contains
locked, transient, or disappearing files. Closing the app window must still stop
owned services and best-effort cleanup must never prevent the next launch.

## Allowed Work

- Minimum launcher lifecycle and cleanup fixes.
- Regression tests for locked/disappearing browser profile entries and owned
  service shutdown.
- Launcher/operator documentation and completion evidence.

## Forbidden Work

- Runtime, provider, tool, workspace, UI, nested repository, or unrelated release
  architecture changes.

## Acceptance Criteria

- `Linlin-Agent.bat run` starts the backend, UI, and one app window.
- Closing that window stops owned services.
- Cleanup races, missing files, or locked browser-profile artifacts are warnings,
  not launch-blocking fatal errors.
- Launcher tests, verify/smoke, frontend, backend, and release checks pass.
