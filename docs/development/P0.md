# P0 — Build and Test Stabilization

**Status:** READY  
**Type:** Stabilization  
**Purpose:** Restore the existing Linlin Agent codebase to a clean, buildable, testable baseline without adding features or redesigning architecture.

## 1. Objective

Fix only actual blockers preventing the existing project from compiling, linting, testing, or building.

## 2. Required Reading

- `AI_COLLABORATION_CHARTER.md`
- `AGENTS.md`
- `docs/standards/Engineering_Standard.md`
- `docs/standards/Testing_Standard.md`
- `docs/architecture/System_Architecture.md`
- this file

## 3. Allowed Work

- syntax and indentation fixes;
- broken import fixes;
- dependency fixes strictly required to run existing code/tests;
- build/test blocker fixes;
- minimal configuration fixes needed for existing validation;
- minimal repairs to malformed generated code.

## 4. Forbidden Work

- new features;
- architecture redesign or framework replacement;
- broad cleanup/refactoring;
- Provider architecture redesign;
- RAG, Memory, MCP, Scheduler, Plugin, Multi-Agent development;
- UI redesign;
- unrelated performance optimization.

## 5. Architecture Invariants

Preserve ProviderManager, ToolLoop, Universal ToolParser, Provider/Tool/Workspace separation, and cross-platform intent.

## 6. Deliverables

- buildable/testable baseline;
- minimal blocker fixes only;
- tests repaired only when the test itself is wrong, never to hide a product defect.

## 7. Acceptance Criteria

- Python modules compile;
- Ruff reports no current-stage violations;
- backend tests pass;
- frontend production build passes when present;
- frontend lint passes when defined by the repository;
- no unrelated feature changes are present in the diff.

## 8. Required Validation

Backend, from the backend project directory or repository-correct equivalent:

```bash
python -m compileall app tests
python -m ruff check app tests
python -m pytest tests -q
```

Frontend, when present:

```bash
npm run build
npm run lint
```

If `lint` is not defined, report that fact; do not invent unrelated tooling during P0.

## 9. Completion Report

Report root causes, modified files, reason for each change, exact validation commands/results, remaining blockers/risks, and any deviations.

## 10. Mandatory Stop Gate

**STOP after P0. Do not begin P1.**  
P1 requires ChatGPT review = **PASS** and explicit project-owner approval.
