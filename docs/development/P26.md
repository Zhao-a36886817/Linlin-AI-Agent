## Objective

Turn the existing RAG, MCP, multi-agent orchestration, and Scheduler safety
runtimes into real, bounded product operations through the shared API and React
control center. No fake adapters or unrestricted execution are permitted.

## Allowed Work

- Product service wiring that injects existing runtime dependencies without
  rewriting the accepted RAG, MCP, orchestration, or scheduler cores.
- Workspace-bounded local RAG ingestion/search with citations and consent.
- Explicitly approved loopback MCP HTTP sessions, discovery, and Tool Runtime
  invocation with schema/timeout enforcement.
- Bounded local-model multi-agent runs with status and cancellation.
- Persistent local scheduler state for an allowlisted chat action, explicit
  consent, audit state, cancellation, and bounded background ticking.
- API/UI contracts and security/regression tests for these operations.

## Forbidden Work

- Arbitrary shell commands, unrestricted paths, remote MCP by default, hidden
  cloud transfer, embedded secrets, fake results, or bypass of Provider/Tool/
  Workspace/Credential boundaries.
- Rewriting core runtimes or unrelated architecture.

## Acceptance Criteria

- RAG, MCP, Multi-agent, and Scheduler pages perform real bounded operations.
- Disabled/empty/error/running/completed states are truthful and actionable.
- Local paths remain inside Workspace Runtime; MCP is loopback and deny-by-default.
- Multi-agent and scheduled model calls use user-selected discovered local models.
- Targeted security tests, full backend regression, frontend, desktop, and release
  checks pass.

Use `begin`, full `validate`, ChatGPT review, owner approval, then transition to P27.
