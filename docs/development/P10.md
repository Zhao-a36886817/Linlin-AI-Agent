## 4. Forbidden Work

- Silent retention or cross-user access.
- RAG implementation.
- Work assigned to any later P stage.
- Advancing `.laes/CURRENT_PHASE.yaml` without the required gate.

## 5. Architecture Invariants

- Memory is invoked only through Agent Runtime.
- Stored data has owner, scope, retention and deletion semantics.
- Secrets are never stored as memory.
- Provider, Tool, Workspace, and Credential Runtime boundaries remain intact.
- Windows, Linux, and macOS remain first-class targets.

## 7. Acceptance Criteria

- Memory remains disabled until explicitly enabled.
- Session and user scopes cannot leak across boundaries.
- Delete and retention behavior is test-covered.
- P0–P9 regression validation remains green.
- No unrelated feature, framework replacement, or future-phase work is present.
