# P33 — Six Global Product Themes

**Status:** READY  
**Type:** product-design  
**Authority:** Project Owner request, 2026-08-09

## Objective

Add six coherent, persistent global themes to the complete Linlin UI: Light, Dark,
Ocean, Forest, Twilight, and Warm Sand.

## Constraints

- Theme state is a non-secret UI preference and may use browser local storage.
- Runtime logic, providers, credentials, workspace and APIs are unchanged.
- All six themes cover navigation, surfaces, inputs, chat, Code, training charts,
  banners and responsive layouts through shared design tokens.
- Preserve readable contrast, focus visibility, reduced motion, and mobile layout.

## Acceptance Criteria

- Six named themes are selectable from the global top bar.
- Selection persists across reload and safely falls back to Light.
- The complete product surface uses theme tokens without unreadable fixed colors.
- Frontend build/lint, full regression, Cargo and visual checks pass.
