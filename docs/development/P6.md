# P6 — Provider Cost and Availability Classification

**Status:** LOCKED  
**Type:** Product/provider policy  
**Purpose:** Prevent Linlin Agent from mislabeling paid or limited cloud services as permanently free and make local-free providers the safe default.

## 1. Objective

Implement provider availability/cost classification using these canonical categories:

- `LOCAL_FREE`
- `FREE_TIER`
- `PAID`
- `UNKNOWN`

Only locally operated providers that do not incur third-party API usage charges may be enabled as `LOCAL_FREE` by default, subject to model/software license terms.

## 3. Allowed Work

- provider metadata for cost/availability class;
- settings/UI labels that accurately reflect classification;
- default-enable/default-disable policy;
- documentation of verification source/date for cloud classifications;
- tests preventing unsupported `FREE` claims.

Local runtimes such as Ollama, LM Studio, llama.cpp server, and local vLLM may be classified `LOCAL_FREE` for API-usage purposes, while model licenses remain separately governed.

## 4. Forbidden Work

- claiming a cloud API is permanently free without current authoritative evidence;
- silently converting `UNKNOWN` to `FREE_TIER`;
- enabling paid providers by default with hidden cost exposure;
- embedding API keys;
- changing provider network implementations unrelated to classification.

## 5. Evidence Rule

Cloud classifications are time-sensitive. A `FREE_TIER` classification MUST record an authoritative source and verification date in project documentation or metadata. If current evidence is unavailable, classify as `UNKNOWN` rather than guessing.

## 6. Deliverables

- canonical classification enum/metadata;
- local-free defaults;
- accurate user-facing labels;
- verification metadata/documentation for cloud free tiers;
- regression tests for classification behavior.

## 7. Acceptance Criteria

- no generic ambiguous `FREE` category exists;
- local-free and free-tier are visibly distinguishable;
- `PAID` and `UNKNOWN` providers are not presented as free;
- cloud free-tier claims have source/date evidence or remain `UNKNOWN`;
- P0-P5 validation remains green.
